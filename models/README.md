# WRO 2026 Future Engineers - Custom 3D-Printed Robot Parts

## Overview

This document presents the custom mechanical parts designed for our robot for the **WRO 2026 Future Engineers** competition. All models shown below were created by our team and manufactured using 3D printing.

The design is divided into modular bases and supports so that the robot's mechanical and electronic components can be mounted securely and organized clearly.

## Component Summary

| File name | Component | Main function |
|---|---|---|
| `b_principal` | Main chassis | Supports the drivetrain, steering system, LiDAR, and battery |
| `b_battery` | Battery mount | Secures the battery to the main chassis |
| `b_camera` | Camera mount | Supports and positions the camera |
| `b_connector` | Connector base | Provides a mounting surface for the electronic components and connections |
| `b_raspberry` | Raspberry Pi base | Holds the Raspberry Pi 4 main controller |
| `b_servo` | Steering servo mount | Holds the steering servomotor at the front of the robot |
| `s_b_connector` | Connector-base support | Supports the connector base within the robot assembly |

## Mechanical Parts
